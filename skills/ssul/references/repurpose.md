# Repurpose other content into a post

Use when the user gives a blog post, newsletter, talk transcript, video script, README, release notes, or a long chat, and wants a Threads or X post from it.

## Steps

1. **Find the one thing.** Read the whole source and pick the single most useful or surprising point for a stranger. Not a summary of everything.
2. **Pick the shape** from what that point is: a number or result (Finding), a mistake (Confession), a belief it breaks (Reversal), a set of steps (List), an opinion (Hot take).
3. **Translate the register.** Source text is usually written (하다체, 하십시오체, report style). Rewrite in the post's register; never paste paragraphs.
4. **Keep facts exact.** Numbers, names, and claims stay as in the source. Do not round up, generalize a sample, or drop a condition.
5. **Strip insider context.** Project names, internal terms, and references to "this article" go; a stranger reads the post without the source.
6. **Link last.** If the user wants to link the source, put it in the first reply, not the first post. Say "링크는 댓글에" only if it adds something.
7. Run all passes in SKILL.md, including disclosure if the source is sponsored or promotes the user's product.

## One source, several posts

If the source has more than one strong point, offer up to 3 separate posts (different shapes), not one long thread, unless the user asks for a thread (`threads.md`).
