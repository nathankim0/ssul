# Polish: meaning first, then spelling

Polish mode edits someone's existing text. The text is the author's; you change how it reads, never what it says.

## 1. Lock the meaning

Before editing, list (for yourself) what must survive:

- who did what to whom
- numbers, units, dates, ranges, names, links
- negation (안, 못, 없다, 아니다) and its scope
- limits and conditions: 만, 까지, 전에는, 이내, ~면, 단
- obligation vs possibility: 해야 한다 vs 할 수 있다 vs 하면 좋다
- hedges the author meant: 아마, 같다, 일 수도
- the author's own judgment and feelings
- quotes, which stay exactly as written

After editing, compare against the list. If anything changed, restore it. `7일 이내에만 가능` is not `7일 이내에 가능`; the first closes the door after 7 days.

Do not add facts, reasons, experiences, jokes, or slang the author did not write. Do not delete a claim to make the text shorter. If a sentence is ambiguous, keep it rather than guess.

## 2. Edit for voice

Apply `korean-voice.md` (AI tells, spoken register) at the strength the request asks for. Keep the author's register unless they asked to change it; if they did, change only the endings and formality, not the content.

## 3. Proofread

Fix clear errors in standard Korean spelling and spacing. Common ones:

| Error | Fix |
|---|---|
| 되/돼 | 돼 = 되어 (돼요, 됐다); 되 before 고/는/면 (되고, 되면) |
| 안/않 | 안 = adverb (안 가요); 않 = 지 않다 (가지 않아요) |
| 로서/로써 | 로서 = as (role); 로써 = by means of |
| 바램 | 바람 |
| 몇일 | 며칠 |
| 어떻해 | 어떡해 / 어떻게 해 |
| 메세지 | 메시지 |
| 할께요 | 할게요 |
| 왠지 / 웬일 | 왠지 (왜인지), 웬일 (어찌 된 일) |
| dependent nouns | 할 수 있다, 한 지 3년, 먹을 거야 (spaced) |

Do **not** "correct" the post's intentional casual style: ㅋㅋ, ㅠㅠ, 반말 contractions (했음, 그럼, 근데), deliberate fragments, internet spellings the author uses on purpose (ㄹㅇ, 개웃김). In doubt, leave it and mention it in one line.

## 4. Report

Return the polished text, then only the changes that matter (meaning-adjacent edits, spelling fixes), one line each. Do not list cosmetic edits.
