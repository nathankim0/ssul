# Analyze posts that worked

Use when the user pastes posts from their feed ("이거 봐", "이런 식으로", "왜 터졌어?"). The goal is a pattern the user can reuse with their own material, not a copy.

## For each pasted post

| Field | What to write |
|---|---|
| Shape | Scene, Confession, Reversal, List, Question, One-liner, Finding, Hot take |
| First line | the line, and which trigger it uses (number, quote, confession, reversal, shared moment, question) |
| Register | 반말 혼잣말, 해요체, 음슴체, 하십시오체; ㅋㅋ and emoji use |
| Engine | what makes people react: usable info, a feeling they share, attitude, a fight to join, a number |
| Length | lines and rough characters |
| Close | how it ends: quote, verdict, question, nothing |
| Steal | one thing worth reusing |
| Skip | anything that would fail ssul's passes (AI tells, bait, undisclosed sponsorship) |

## Across all pasted posts

One short summary:

- the register most of them use (this becomes the voice source in Step 2)
- the 2 or 3 shapes that dominate
- typical length
- what the user's material would need to fit in (e.g. "a number from your own test", "an attitude about a trend")

## Then

Offer 1 to 3 post ideas that use the user's real material in those shapes. If the user has no matching material, say what material would be needed instead of inventing it.

Never reuse another person's text, numbers, or story as the user's.
