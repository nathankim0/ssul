# Profile (Threads, Instagram, X)

Use when the user asks to write or fix their bio. A stranger who liked one post decides in a few seconds whether to follow.

## Parts

| Part | Rule |
|---|---|
| Name | the name people will search, plus one keyword if the field allows (e.g. "김OO · 농사 기록"). No emoji walls. |
| Bio line 1 | who the user is, concretely: role, place, or what they do daily |
| Bio line 2 | what followers get here: the 2 or 3 pillars, in plain words |
| Bio line 3 (optional) | one real proof: a number, a project, years doing it. Only if true. |
| Link | one link, the thing the user most wants clicked |
| Pinned post | the post that best shows what the account is for, usually a Finding or the best-performing post |

## Rules

- Same register as the user's posts.
- Specific beats grand: "매일 아침 6시 밭 일지" beats "농업의 미래를 고민합니다".
- No unverifiable titles ("최고", "1위", "전문가") unless the user can back them; advertising rules apply to business accounts.
- Business or sponsored accounts state the relationship plainly (`disclosure.md`).
- Threads bios are short; aim for 3 lines or fewer.

## Output

2 options with different angles (who you are vs what followers get), and a pick.
