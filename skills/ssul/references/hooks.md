# First lines

Pick 3 candidates from different triggers, run the four killers (late, confusing, not mine, flat), keep the best. Fill every slot with real material. Korean wording below is written for Korean, not translated.

## Triggers

### 1. Specific number
- `[숫자][단위]: [그게 뭔지]`
  - 16개: 스레드 글 하나 쓰려고 깐 스킬 수
- `[시각]에 [작은 사건]`
  - 밤 9시에 아빠가 숟가락을 내려놨어요

### 2. Quoted line
- `"[누가 한 말]" [반응]`
  - "스킬 쓴 거 맞아?" 물었더니 "아니요"래요
- `[누구]가 [상황]에서 한 말`
  - 퇴근하는데 팀장님이 "내일 하자"고 했어요

### 3. Confession
- `[작은 목표] 하려다가 [과한 결과]`
  - 스레드 글 하나 써달라 했다가 스킬만 16개 깔았어요
- `[부끄러운 사실] 고백하자면`. Use only when what follows is genuinely embarrassing.

### 4. Reversal
- `[다들 하는 것] 했는데 [반대 결과]`
  - 서리 온다고 밤새 무 뽑았는데 서리 안 왔어요
- `[통념]인 줄 알았는데 [구체적 사실]`. Both halves must be concrete.

### 5. Shared moment
- `[누구나 겪는 순간]`, with no setup
  - 회의 끝나고 "정리해서 공유드릴게요" 말한 사람이 그 일 다 하는 거
- `[구체적 장면] 아는 사람`

### 6. Question
- Only when the user wants answers.
  - 팀 CLAUDE.md에 어디까지 넣으세요?

## Killers, with Korean examples

| Killer | Bad | Fixed |
|---|---|---|
| Late | 요즘 AI 관련해서 느끼는 게 많은데요 | 클로드한테 글 써달라 했다가 스킬만 16개 깔았어요 |
| Confusing | 윤문 스킬 붙이니 내용은 가짜라더라 | 말투는 고쳤는데 진짜 있었던 일을 달래요 |
| Not mine | 저는 요즘 생산성에 관심이 많아요 | 회의 끝나고 "제가 정리할게요" 했다가 일 다 떠안은 적 있죠 |
| Flat | 오늘 무를 뽑았어요 | 서리 온다고 밤새 무 뽑았는데 서리 안 왔어요 |

## Banned openers
- 인사, 자기소개, "오늘은 ~에 대해"
- "여러분 그거 아세요?" with no named thing
- "충격", "역대급", "미쳤다" without a fact behind it
- "아무도 말 안 해주는" when everyone says it
- A call to action as the first line
