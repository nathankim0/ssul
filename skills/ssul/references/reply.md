# Replies and quote posts

On Threads, replies are the conversation and the strongest engagement signal. A good reply is short, specific to that post, and adds one thing.

## Input

The original post text (pasted; ssul cannot fetch posts by URL), plus what the user wants: agree, disagree, add, ask, joke.

## Pick what to add (exactly one)

| Add | When |
|---|---|
| a concrete fact or number the user knows | the post makes a claim the user can support or correct |
| the user's own case | the post asks or describes something the user has lived |
| a precise question | something in the post is unclear or worth digging into |
| a counterpoint with a reason | the user disagrees; one reason, no lecture |
| a one-line reaction | the post is a joke or a feeling; match its energy |

## Rules

- Match the original post's register (반말 to 반말, 해요체 to 해요체), unless the user is replying to a stranger in 반말 and might sound rude; then use light 해요체.
- 1 to 3 lines. A reply longer than the post is a post; suggest a quote post instead.
- Refer to something specific in the post, so it could not be pasted under any other post.
- No "좋은 글 감사합니다", "공감합니다" with nothing after it, no self-promotion, no link unless asked.
- Disagree with the claim, not the person.
- Real material rules still apply: the user's facts only.

## Quote post

Use when the user's addition stands on its own for their followers. First line is the user's take, written as a full post that makes sense without reading the quoted one. Then the shapes and passes from SKILL.md apply.

## Output

2 or 3 reply options with different "adds", each labeled in a few words, and a pick.
